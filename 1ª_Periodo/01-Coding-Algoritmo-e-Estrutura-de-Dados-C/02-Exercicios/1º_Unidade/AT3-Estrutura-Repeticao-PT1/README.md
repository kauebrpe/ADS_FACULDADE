# Atividade 4 - Estrutura de Repetição

**Unidade:** I Unidade

## Instruções

Todos os algoritmos devem ser desenvolvidos em **linguagem C**.

### Exercícios

**1.** Faça um algoritmo que lê números inteiros positivos, um de cada vez, até que o número zero seja digitado, e exibe o maior número lido.

**2.** Faça um algoritmo para calcular a média de 50 alunos de uma turma usando `while`.

**3.** Faça um algoritmo para calcular a média dos 50 alunos com teste no final usando o comando `do-while`.

**4.** Faça um algoritmo para calcular a média dos 50 alunos usando repetição fixa (`for`).

**5.** Escreva um algoritmo que lê 50 números inteiros e, em seguida, mostre a soma de todos os ímpares lidos.

**6.** Escreva um algoritmo que lê 50 números inteiros e, em seguida, mostre a soma dos ímpares que estejam entre 100 e 200.

**7.** Construa um algoritmo que leia um conjunto de 20 números inteiros e mostre qual foi o maior e o menor valor fornecido.

**8.** Escreva um programa que calcula o produto de dois números lidos sem usar o operador de multiplicação (`*`).

**9.** Construa um algoritmo que fique lendo indefinidamente números positivos. Caso o número lido seja igual a 0, o algoritmo para de ler números e imprime a média dos números pares lidos anteriormente.

**10.** Foi feita uma pesquisa com 15 pessoas na saída do cinema que estava passando o filme “Vingadores – Guerra Infinita”. Cada pessoa informava sua idade, sexo (1-Fem / 2-Mas) e opinião sobre o filme (1-Não gostei / 2-Esperava mais / 3-Vale o ingresso / 4-Excelente).

Faça um algoritmo que leia os dados da pesquisa e apresente os seguintes resultados:

a. Média da idade das mulheres que acharam o filme Excelente;

b. Percentual de homens que não gostaram do filme;

c. Quantidade de pessoas que esperavam mais do filme.

**11.** Foi feita uma pesquisa de audiência nos canais de TV aberta em várias casas de uma cidade. Para cada casa foi perguntado o canal (1-SBT / 2-Record / 3-Globo / 4-Rede TV) e o número de pessoas que estavam assistindo no momento.

A quantidade de casas pesquisadas é desconhecida. Faça um algoritmo que encontre:

a. Percentual de audiência para cada canal;

b. Canal com maior audiência;

c. Canal com menor audiência.

## Desafio

Escreva um programa que lê um número e, em seguida, calcula e imprime seu fatorial.
