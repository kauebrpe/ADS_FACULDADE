# Atividade 5 - Estrutura de Repetição

**Unidade:** I Unidade

## Instruções

### Exercícios

**1.** Escreva um programa que imprima os números de 1 a 10 usando `while`.

**2.** Faça um programa que leia um número e exiba a tabuada dele (de 1 a 10) usando `while`.

**3.** Crie um programa que conte quantos números pares existem entre 1 e 50 usando `while`.

**4.** Desenvolva um programa que leia números até que o usuário digite 0 e mostre a soma dos valores.

**5.** Faça um programa que leia a senha correta (1234) e continue pedindo até o usuário acertar.

**6.** Escreva um programa que peça um número positivo. Continue pedindo enquanto o valor for negativo.

**7.** Crie um programa que exiba os números de 1 a 10 usando `do...while`.

**8.** Faça um programa que leia vários números até o usuário digitar -1 e mostre a média.

**9.** Desenvolva um programa que simule um menu simples (1 - opção A, 2 - opção B, 0 - sair), repetindo até o usuário escolher sair.

**10.** Escreva um programa que imprima os números de 1 a 20 usando `for`.

**11.** Faça um programa que mostre apenas os números ímpares de 1 a 50.

**12.** Crie um programa que calcule a soma dos números de 1 a N (valor informado pelo usuário).

**13.** Desenvolva um programa que imprima a tabuada de todos os números de 1 a 5.

**14.** Faça um programa que conte quantos números entre 1 e 100 são divisíveis por 3.
