# Introdução a Banco de Dados e SGBD

## O que é um Banco de Dados?

Um Banco de Dados é um conjunto organizado de informações armazenadas de forma estruturada.

O objetivo é permitir que os dados possam ser consultados, alterados e gerenciados de maneira eficiente.

---

## Exemplos do Dia a Dia

### Escola

Dados armazenados:

- Alunos
- Professores
- Turmas
- Notas

---

### Loja Virtual

Dados armazenados:

- Clientes
- Produtos
- Pedidos
- Pagamentos

---

### Hospital

Dados armazenados:

- Pacientes
- Médicos
- Consultas
- Exames

---

## O que é um SGBD?

SGBD significa:

```text
Sistema Gerenciador de Banco de Dados
```

É o software responsável por gerenciar os bancos de dados.

Funções principais:

- Armazenar dados
- Consultar dados
- Atualizar dados
- Excluir dados
- Controlar acessos
- Garantir integridade

---

---

---

### Oracle Database

---

### SQL Server

## Banco de Dados x SGBD

Muita gente confunde os dois conceitos.

### Banco de Dados

É o conjunto de informações.

Exemplo:

```text
Escola
```

contendo:

```text
Alunos
Turmas
Notas
```

---

### SGBD

É o programa utilizado para gerenciar esses dados.

Exemplo:

```text
MySQL
```

---

## O que é SQL?

SQL significa:

```text
Structured Query Language
```

É a linguagem utilizada para trabalhar com bancos de dados relacionais.

Com SQL podemos:

- Criar tabelas
- Inserir dados
- Consultar dados
- Atualizar dados
- Excluir dados

---

## Exemplo de Consulta SQL

```sql
SELECT *
FROM alunos;
```

Esse comando consulta todos os registros da tabela.

---

## Erros Comuns

### Erro 1

Pensar que MySQL é um Banco de Dados.

Correto:

```text
MySQL é um SGBD.
```

---

### Erro 2

Confundir SQL com MySQL.

Correto:

```text
SQL = Linguagem

MySQL = SGBD
```

---

### Erro 3

Pensar que uma tabela é um banco de dados.

Um banco de dados pode conter diversas tabelas.

---
