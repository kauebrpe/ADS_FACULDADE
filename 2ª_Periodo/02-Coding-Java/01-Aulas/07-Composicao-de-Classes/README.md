# Composição de Classes

Este módulo apresenta um dos conceitos mais importantes da Programação Orientada a Objetos: a composição.

A composição permite que uma classe utilize objetos de outras classes para construir sistemas mais organizados e próximos da realidade.

Enquanto a herança utiliza a relação:

```text
É UM
```

a composição normalmente utiliza a relação:

```text
TEM UM
```

ou

```text
POSSUI UM
```

# Relação de Composição

Exemplo:

```text
Pedido
↓
Cliente
```

Um pedido possui um cliente.

---

Outro exemplo:

```text
Carro
↓
Motor
```

Um carro possui um motor.

---

Outro exemplo:

```text
Computador
↓
Processador
```

Um computador possui um processador.

---

# Relação com Herança

## Herança

Representa:

```text
É UM
```

Exemplo:

```text
Aluno é uma Pessoa
```

---

## Composição

Representa:

```text
TEM UM
```

Exemplo:

```text
Pedido tem um Cliente
```

---

# Benefícios da Composição

- Reutilização de código
- Maior organização
- Menor acoplamento
- Melhor manutenção
- Modelagem mais próxima do mundo real
