# Polimorfismo e Interfaces

Este módulo apresenta conceitos avançados de Programação Orientada a Objetos que são construídos sobre herança e sobrescrita.

Aqui aprenderemos como diferentes objetos podem responder de formas distintas ao mesmo método e como interfaces ajudam a definir contratos para classes.

Esses conceitos são muito utilizados em sistemas profissionais desenvolvidos em Java.
