# Programação Orientada a Objetos com Java

Este diretório reúne os conteúdos estudados durante a disciplina de Programação Orientada a Objetos utilizando Java.

O foco da disciplina é desenvolver a base necessária para construir aplicações orientadas a objetos, utilizando os conceitos fundamentais da linguagem Java e os principais pilares da Programação Orientada a Objetos.

# Conceitos Importantes

## Java

Linguagem de programação orientada a objetos criada para ser independente de plataforma.

---

## JVM

Java Virtual Machine.

Responsável por executar aplicações Java.

---

## JRE

Java Runtime Environment.

Ambiente necessário para executar aplicações Java.

---

## JDK

Java Development Kit.

Conjunto de ferramentas necessárias para desenvolver aplicações Java.

---

# Pilares da Orientação a Objetos

## Encapsulamento

Protege os dados da classe.

---

## Herança

Permite reutilização de código.

---

## Polimorfismo

Permite comportamentos diferentes para objetos relacionados.

---

## Abstração

Representa apenas as características importantes de um objeto.
