# Lógica de Programação

Este módulo apresenta os conceitos fundamentais de programação utilizando Java.

O objetivo é desenvolver a capacidade de resolver problemas através de algoritmos antes de avançar para Programação Orientada a Objetos.

Todos os tópicos deste módulo servem como base para os próximos conteúdos da disciplina.

# Conceitos Fundamentais

## Variável

Espaço utilizado para armazenar informações.

Exemplo:

```java
int idade = 20;
```

---

## Condição

Expressão que retorna:

```java
true
```

ou

```java
false
```

---

## Repetição

Permite executar o mesmo bloco várias vezes.

Exemplos:

```java
for
```

```java
while
```
