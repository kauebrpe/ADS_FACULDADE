# Introdução ao Java

Este módulo apresenta os conceitos fundamentais da linguagem Java e da plataforma Java.

O objetivo é compreender como a tecnologia funciona antes de começar a programar utilizando Programação Orientada a Objetos.

Os conceitos abordados aqui servem como base para todos os módulos seguintes da disciplina.

# Visão Geral da Plataforma Java

Estrutura simplificada:

```text
JDK
│
├── JRE
│   │
│   └── JVM
```

---

# Fluxo de Execução

Quando criamos um programa Java:

```text
Arquivo .java
        ↓
Compilação (javac)
        ↓
Arquivo .class
        ↓
JVM
        ↓
Execução
```

---

# Conceitos Fundamentais

## Java

Linguagem de programação orientada a objetos.

---

## JVM

Máquina virtual responsável por executar programas Java.

---

## JRE

Ambiente necessário para executar aplicações Java.

---

## JDK

Conjunto de ferramentas para desenvolvimento.

---

## Bytecode

Código intermediário gerado pelo compilador Java.
