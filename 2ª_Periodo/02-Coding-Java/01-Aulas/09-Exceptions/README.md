# Exceptions

Este módulo apresenta o tratamento de erros em Java.

Durante a execução de um programa podem acontecer situações inesperadas:

- Divisão por zero
- Arquivo inexistente
- Entrada inválida do usuário
- Índices inexistentes em listas

Esses problemas são chamados de exceções (Exceptions).

Java possui mecanismos próprios para detectar, tratar e controlar essas situações.

# Por Que Estudar Exceptions?

Sem tratamento de erros:

```text
Programa encerra abruptamente.
```

---

Com tratamento de erros:

```text
Programa continua funcionando.
```

---

# Exemplo de Problema

```java
int resultado = 10 / 0;
```

Resultado:

```text
ArithmeticException
```
