# Coleções

Este módulo apresenta as principais estruturas utilizadas para armazenar e manipular grupos de objetos em Java.

Até agora trabalhamos com variáveis isoladas e objetos individuais.

A partir deste módulo aprenderemos a trabalhar com conjuntos de informações de forma organizada e eficiente.

# Por Que Estudar Coleções?

Imagine uma turma com 40 alunos.

Sem coleções precisaríamos de:

```java
Aluno aluno1;
Aluno aluno2;
Aluno aluno3;
...
```

---

Utilizando coleções:

```java
List<Aluno> alunos;
```

---

A organização fica muito melhor.

---

# Vantagens das Coleções

- Organização
- Facilidade de manutenção
- Flexibilidade
- Reutilização
- Menos código repetido
