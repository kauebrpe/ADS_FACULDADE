# Modelagem de Dados

## Objetivo do Bloco

Este bloco apresenta a modelagem de dados, responsável por transformar regras de negócio em estruturas que podem ser implementadas em bancos de dados.

Ao final deste módulo você será capaz de:

- Criar modelos conceituais
- Criar modelos lógicos
- Criar modelos físicos
- Construir DERs
- Identificar cardinalidades
- Transformar DER em tabelas
- Aplicar normalização
