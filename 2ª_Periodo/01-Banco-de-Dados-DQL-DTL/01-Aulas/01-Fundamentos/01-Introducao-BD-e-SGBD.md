# Introdução a Banco de Dados e SGBD

## Objetivo

Compreender os conceitos fundamentais de Banco de Dados (BD) e Sistema Gerenciador de Banco de Dados (SGBD).

Este é o assunto mais básico da disciplina e serve como base para todos os demais conteúdos.

---

# O que é um Banco de Dados?

Um Banco de Dados (BD) é um conjunto organizado de informações armazenadas para consulta e manipulação.

O objetivo de um banco de dados é armazenar informações de forma segura, organizada e acessível.

# O que é um SGBD?

SGBD significa:

```text
Sistema Gerenciador de Banco de Dados
```

É o software responsável por criar, armazenar, gerenciar e proteger os dados.

Sem um SGBD seria necessário controlar manualmente todos os arquivos e informações.

---

# Principais Funções de um SGBD

Um SGBD é responsável por:

✅ Armazenar dados

✅ Consultar dados

✅ Atualizar dados

✅ Excluir dados

✅ Controlar acesso

✅ Garantir integridade

✅ Fazer recuperação em caso de falhas

# Banco de Dados x SGBD

Uma confusão comum é pensar que Banco de Dados e SGBD são a mesma coisa.

Não são.

## Banco de Dados

É o conjunto de informações.

Exemplo:

```text
Escola_DB
```

---

## SGBD

É o programa que gerencia essas informações.

Exemplo:

```text
MySQL
```

---

# Erros Comuns

## Erro 1

Pensar que MySQL é um Banco de Dados.

Errado:

```text
MySQL = SGBD
```

---

## Erro 2

Confundir SQL com MySQL.

Errado:

```text
SQL = Linguagem

MySQL = SGBD
```

---

## Erro 3

Achar que um banco é apenas uma tabela.

Um banco pode possuir dezenas ou centenas de tabelas.

---

# Resumo

## Banco de Dados

Conjunto organizado de informações.

---

## SGBD

Software que gerencia os dados.

---

## SQL

Linguagem utilizada para interagir com o banco.

---

## MySQL

SGBD utilizado nesta disciplina.

---

# Cola para Prova

```text
BD = Dados

SGBD = Gerencia os dados

SQL = Linguagem

MySQL = SGBD

Banco de Dados ≠ SGBD
```
